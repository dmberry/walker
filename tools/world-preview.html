WALKER

BETA · VERSION

An isometric world for a three-dimensional character. The figure is posed and animated each frame rather than picked from baked sprites, and the world around him — terrain, trails, weather of a kind, a day that passes — is generated rather than drawn.

It runs from a single HTML file with no build step, no bundler and nothing fetched over the network.
