share-card.png   600x315, what the meta tags point at

Drawn to a canvas rather than authored as a file: the wordmark is letter-spaced
by hand and macOS Quick Look would not honour an SVG viewBox for the render, so
the card is generated by the same code that draws the game's own signage.

600x315 is the documented minimum for a large Open Graph / Twitter card and
keeps the file at 8 KB. Flat colour on purpose — a gradient dithers, dither is
noise, and noise is what a PNG cannot compress.
